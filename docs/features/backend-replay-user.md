# Replay demo

Demo supplies synthetic thermal frames without connecting a camera. Its temperatures are illustrative, not measurements.

## Run the demo

Choose Demo, a camera profile and a thermal video mode, then Start. A moving warm spot crosses the image. Stop releases the timer. The replay backend does not send camera commands or read `.irvis` files; file playback belongs to #19.
