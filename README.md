# irvis

An open-source viewer for USB-C thermal cameras: a desktop app for macOS, Windows and Linux, and an experimental web version, sharing one TypeScript core and one UI. Work in progress: the repository has the toolchain, the core types, the camera registry (no camera yet) and a placeholder web page. The first camera will be the TOOLTOP T7 (InfiRay P2 Pro).
